# Legacy Snapshot (Untracked)

This directory is reserved for the full pre-AgentKit codebase. Populate it locally with the archived tree (zip, tar, or raw files) when you need quick reference, but those assets are intentionally ignored by Git so day-to-day work stays clean.

If you ever need the snapshot in version control, use the `legacy` tag/branch or add a new archive artifact (e.g., a zip) elsewhere in the repo. Otherwise leave the files here untracked.
